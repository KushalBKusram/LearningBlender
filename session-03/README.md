# Session 03: Modeling Toolkit I — Edit Mode

**Goal:** Learn direct mesh editing.

**Skills:** Vertex/edge/face selection, extrude, loop cut, bevel, inset, merge.

**Deliverable:** Model a simple low-poly prop (e.g. mug or chair) from a single primitive.

## Files
- Put your .blend file(s) for this session directly in this folder.
- Renders/exports go in a `renders/` subfolder if you produce any.
