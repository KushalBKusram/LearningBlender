# Session 12: Rigging Basics

**Goal:** Build a controllable skeleton for an object/character.

**Skills:** Armatures, bones, parenting with weights, basic weight painting.

**Deliverable:** A simple rig that can be posed without breaking the mesh — rig the Session 10 sculpt if it's a capstone character.
